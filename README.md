# movie_recommender-svd
A movie recommendation system using linear algebra and the MovieLens 100K dataset for MATH 344L

## Dataset

This project uses the MovieLens 100K dataset provided by GroupLens Research at the University of Minnesota. The dataset contains 100,000 movie ratings from 943 users across 1,682 movies.

**Source:** GroupLens Research - MovieLens 100K Dataset

**Dataset Link:** https://grouplens.org/datasets/movielens/100k/

We use this dataset to build and test a movie recommendation system using linear algebra, including rating matrices, baseline models, and Singular Value Decomposition (SVD).
